Install ffmpeg (only if it's missing)

The desktop downloads include ffmpeg. You only need this page if the dashboard says ffmpeg is not installed, or if you run ClipPilot from source.

ClipPilot needs an ffmpeg build with libass, which burns in the captions. All the builds below include it.

Windows

  • With winget, in PowerShell: winget install --id Gyan.FFmpeg -e
  • Or download the "release full" build from https://www.gyan.dev/ffmpeg/builds/, unzip it, and add its bin folder to your PATH.

macOS

  • With Homebrew: brew install ffmpeg

Linux

  • Debian/Ubuntu: sudo apt install ffmpeg
  • Fedora: sudo dnf install ffmpeg (enable RPM Fusion first)
  • Arch: sudo pacman -S ffmpeg

Check it

Run clippilot doctor (or open Settings → About in the dashboard). Every line should say ok. To use a specific ffmpeg, set the environment variables CLIPPILOT_FFMPEG and CLIPPILOT_FFPROBE to their full paths.

ClipPilot is free and open source (MIT). It runs on your computer: no accounts, no servers, no tracking.
